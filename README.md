# 摄影作品集

一个纯静态摄影作品集，适合 GitHub Pages。页面使用本地 WebP 图片，不依赖图片 CDN 或数据库；相册封面会完整并排展示多张照片，点进相册可看简介与完整作品，点击作品进入大图浏览，支持键盘左右键。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8000
```

浏览器打开 <http://localhost:8000>。

## 更新照片

原始照片仍保留在桌面“网站照片”文件夹。本项目内的 `images/` 是网站副本，运行以下命令会按相册目录重新生成 2000px 长边以内的 WebP 图片和 `works.json`：

```sh
python3 scripts/build_assets.py
```

脚本不覆盖或移动原图；生成的 WebP 会去掉 EXIF 元数据，减小页面下载量并避免发布拍摄设备/定位等原始信息。

## 修改站点文案

请在桌面的 Word 文件 **`相册命名和简介填写单.docx`** 中修改作者简介、图集名称和图集简介，再把改好的 Word 交给助手同步到网站。素材文件夹名只用于识别照片，不会显示在网站上。`site-content.json` 是网站运行配置，不作为你的日常编辑入口。

图集封面按照片横竖比例自动排版：竖图占多数时展示最多 3 张竖图；横图占多数时用 1 张横图。照片不会被裁切；数量不足时展示现有照片。
- 在 `author.name` 和 `author.bio` 写首页作者名和简介。
- 首屏三张精选照片由 `author.heroAlbumId` 和 `author.heroCoverIndexes` 控制。

文案为空时网页会显示待填写提示，避免误把文件夹名当成最终图集名称。

不想直接编辑 JSON 的话，先填写 [相册命名和简介填写单](相册命名和简介填写单.md) 发回给我，我可以替你写入网站配置。
